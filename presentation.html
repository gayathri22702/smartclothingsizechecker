Foundational Context

Problem Statement

03
1 📱

Project

Smart Clothing Size Checker is a web/mobile-based system that helps online shoppers select an appropriate clothing size by comparing their personal body measurements with the actual size chart of a selected product and brand.

Considers chest, waist, hip, shoulder, inseam & fit preference (slim, regular, relaxed)
2 ⚠️

Problem

Online shoppers face difficulty choosing the correct clothing size because S, M, L and XL are not standardized across brands.

The same labelled size corresponds to completely different measurements between brands. Shoppers must manually compare charts, guess, order multiple sizes ("bracketing"), or deal with painful returns.

Non-standard sizing causes 30%+ fashion return rates
3 💡

Gap

Existing shopping interfaces generally provide a raw, confusing size chart, but the shopper still has to manually interpret it themselves.

Therefore, there is an urgent need for an explainable, product-specific size recommendation engine rather than merely displaying generic S/M/L labels.

Solution: Explainable recommendation with fit warnings
Figure 2: Overview of the project, the problem and the gap in online clothing size selection. Source: Team study of online clothing size charts and sizing practices.

Design Thinking Phase 2: Define

Defining Insights

06
Need Type Detailed Description
🎯 Primary Need A reliable way to identify the appropriate size for a specific clothing product without relying on generic letter sizes.
⚙️ Secondary Needs Product-specific size comparison, measurement normalization across units (inches vs cm), fit preference accommodation (slim, regular, oversized), tight/loose fit warnings, and simple granular explanations.
✨ Latent Need Confidence and psychological reassurance that the selected size is appropriate before placing the order, eliminating sizing anxiety and reducing uncertainty about fit.

Design Thinking Phase 4: Prototype

Solution Prototype Workflow

09
“Users enter their measurements and select a clothing product. The system compares them with the product’s size chart and recommends the most suitable size based on fit preference and measurement differences.”
1

Registration & Body Profile

User enters chest, waist, hip, shoulder, height, inseam, or uses the Game Avatar creator.

2

Select Garment Product

User selects category (Top vs Bottom) and pastes the e-commerce product link.

3

Size Chart Collection

Obtains size chart via image upload or live viewfinder camera tag scanner.

4

Measurement Normalization

Normalizes units (in/cm) and standardizes anatomical reference baselines.

5

Fit Ease Analysis

Calculates ease tolerances for Fitted / Snug, Regular, or Oversized styles.

6

Explainable Verdict

Displays recommended size, confidence %, tight/loose gauges, and size switcher.

Figure 7: Prototype workflow of the Smart Clothing Size Checker from user measurement input to personalized size recommendation. Source: Proposed system design.

Main Features

10
1

User Account & Auth

Secure login with Google OAuth, Email/Password, or Guest Instant Access.

2

Personal Measurement Profile

Saves chest, waist, hips, shoulder span, height, and leg inseam values.

3

Product & Brand Selection

4

Multi-Modal Size-Chart Input

5

Measurement Normalization

6

Personalized Sizing Matcher

Compares user measurements with each available garment size concurrently.

7

Fit Style Preference

Ecological Responsibility

Design for Environment

12
🔄

LESS RETURNS

Precision ease guidance eliminates the guesswork that forces shoppers to order 2-3 sizes to find one that fits, drastically reducing avoidable size-related exchanges.

📦

LESS PACKAGING

Cutting return transactions prevents millions of tons of single-use corrugated cardboard boxes, poly mailer bags, and plastic adhesive tape from entering landfills.

🌿

LOWER IMPACT

Eliminating reverse logistics transport curtails diesel freight truck miles, air cargo emissions, and warehouse repacking overhead, saving ~2.4 kg of CO₂ per avoided return.
